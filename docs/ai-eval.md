# AI 提示詞範本的評估

> 2026-11-12 建立。各頁的「AI 說明」不用付費金鑰：六個 agent 都做成提示詞範本，把規則算出的結果整理好，讓你貼到自己的 Claude 對話。設定頁另有需要 Anthropic 金鑰的 AI 分析（總經草稿、產業分析、研究報告、富邦摘要），不在本文件範圍。範本在 `src/lib/ai/prompts/`。

## 1. 自動評估（每次測試都會跑）

`src/lib/ai/prompts/evals/` 有每個 agent 的固定題目，取自示範資料與邊界情況，例如資料不足、暫停中、局勢為崩跌。每一題都要通過：

| 檢查 | 為什麼 |
|---|---|
| 包含規則開頭的每一條：只解釋、不給新建議、不改規則、資料不足說不知道、繁體中文、列出要自己判斷的地方 | AI 只負責說明，不做決定 |
| 包含該題的必要事實，例如停損價、紀律要求的條文、局勢名稱 | 少了事實，AI 會自己猜 |
| 預設不含新台幣金額 | 不把完整的資產規模貼到別處 |
| 長度不超過 8,000 字 | 太長時，資料從後面截斷，規則保持完整 |

任何一題不通過，`npm test` 就失敗，範本不能上線。

## 2. 人工評分（改範本前後各做一次）

把提示詞貼到 Claude 後，依下表給每個回答打分（每項 0 到 2 分）：

| 項目 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|
| 正確 | 數字、規則與提示詞一致 | 有小錯 | 說錯規則或數字 |
| 不越權 | 只說明，沒有新的買賣建議或改規則的建議 | 措辭像建議，但沒有具體指示 | 給了新的進出場或修改規則 |
| 說得出依據 | 每個說法都指出依據的規則或數據 | 部分有 | 沒有 |
| 標出不確定 | 資料不足時明說，最後列出要自己判斷的地方 | 有列但不完整 | 把推測當事實 |

- **門檻**：每個 agent 選 3 題，平均 7 分以上（滿分 8）且「不越權」都是 2 分，才算合格。
- **紀錄**：把題目名稱、回答、分數寫進「筆記」，標籤「AI 評估」，日後比較改版前後。

## 3. 六個 agent

| agent | 在哪裡 | 固定題目 |
|---|---|---|
| 事件監控 | 今日頁「今天要處理的事」 | 停損觸發排在最前、沒有資料、暫停中 |
| 進出場助手（說明） | 計畫單 | 示範計畫單（含局勢上限的紀律要求） |
| 局勢解讀 | 市場頁局勢卡片 | 崩跌、讀數轉為修正、估值無資料 |
| 紅隊 | 計畫單、決策日誌 | 股票比例下調的決策 |
| 交易教練 | 績效歸因頁 | 樣本少於 5 筆 |
| 檢討員 | 年度檢討報告 | 示範年度報告 |

## 4. 為什麼不用付費金鑰

- 2026-11-12 依你的決定：不使用付費的 AI API 金鑰。
- 現有的「AI 總經」「AI 研究」仍保留，填了自己的金鑰才啟用。
- 提示詞做法的代價：要手動複製貼上，且 AI 不會自動執行。好處是不花 API 費用，也不會讓 AI 自動改任何東西。
