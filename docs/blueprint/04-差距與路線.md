# 04 差異分析：藍圖與現有系統，下一步該增減什麼

> 規劃文件；整理於 2026-11-11，同日修訂（改寫為差異分析）；2026-11-12 記錄 C 類的刪減決定。本文件比較 [02 平台功能](02-平台功能規劃.md) 與目前網站的實作，分成五類，讓你決定下一步實作要增加、強化、合併或刪減什麼。**刪減只是建議，每一項都由你逐條決定。**

## 摘要：五個最重要的發現

1. **零件大多有了，缺的是把它們串成「進出場助手」的流程。** 研究卡已有三批價位、ATR 停損、建議股數；策略卡有進出場規則；交易前檢核、到價提醒、交易日誌都有。但它們散在不同頁面，沒有「交易計畫單」把一筆交易從進場前到出場後串起來，持有中也沒有人提醒你更新停損。
2. **出場管理最弱。** 研究卡、回測、虛擬帳戶各自計算停損，真實持股卻沒有移動停損、R 倍數與時間停損的追蹤。
3. **局勢判斷有原料、沒有結論。** 每日大盤的趨勢狀態與總經三支柱各自存在，沒有綜合成一個局勢狀態，也沒有「局勢改變，進出場參數跟著改」的機制；目前只有「總經逆風暫停新建倉」一條規則。
4. **風險只看靜態上限。** 有配置偏離、集中度、美元曝險與回撤熔斷，但沒有波動、相關性、壓力測試，看不到「最壞會虧多少」。
5. **有幾項功能依賴付費 AI 或外部格式，維護成本高，與藍圖的核心關係較弱。** 例如富邦報告擷取、AI 研究報告，可以考慮簡化（見 C 類）。

## D. 重複或衝突 → 建議合併

| 總經三支柱 vs 局勢儀表板 | 每月手動的總經判斷，與每日自動的大盤判斷是兩套 | 局勢儀表板為主，總經三支柱變成其中一個面向；月檢視保留，作為人工確認 |

## E. 建議的下一步選項

三個組合可以單獨做，也可以依序做。建議先做組合一：它沿用最多現有零件，最直接改善進出場紀律。

### 組合一：進出場助手的規則層（建議先做）
> **已完成**（2026-11-12，階段 1）：交易計畫頁（投資持有 → 交易計畫）、持股與風控的出場管理、今日頁的「今天要處理的事」、交易日誌的計畫價與滑價。

- **範圍**：
  - 交易計畫單（3.3）
  - 每日掃描（3.1 ①，取代今日頁待辦）
  - 出場管理器（3.6）
  - 執行品質追蹤（3.8）的基本版：計畫價與成交價
  - 研究卡與策略卡的「記錄買進」改為「建立計畫單」
- **沿用**：研究卡價位與停損、策略卡規則、交易前檢核、距買點、交易日誌。
- **工作量**：中，約 1 到 2 週。
- **做完之後能回答**：
  - 每筆持股現在的停損在哪裡？該不該上移？
  - 今天有哪些事要處理？
  - 我有沒有照計畫進出？
- **不需要**：後端、AI 金鑰。

### 組合二：局勢狀態與局勢參數表
> **已完成**（2026-11-12，階段 2）：市場頁的「局勢狀態」、目標與政策頁的「局勢參數表」與「大盤逢低階梯」；交易前檢核的「總經逆風」改為「局勢參數允許新建倉」，研究卡的總經逆風改為建議。

- **範圍**：
  - 局勢狀態：用現有每日大盤的面向，加上總經三支柱
  - 局勢參數表（3.9）
  - 交易前檢核改用參數表（取代「總經逆風」單一規則）
  - 大盤逢低階梯（4.2）
- **工作量**：中，約 1 週。
- **做完之後能回答**：
  - 現在是什麼局勢？
  - 這個局勢下，我的部位、停損、加碼規則是什麼？
- **最好在組合一之後**：參數表要套用到計畫單上，效果才完整。

### 組合三：風險儀表板與壓力測試
- **範圍**：風險儀表板（5.1）、壓力測試（5.2）、連續虧損暫停與單月虧損上限（5.5）。

## F. 不做的事

| 不做 | 原因 |
|---|---|
| 自動下單、連接券商 | 錯誤無法挽回；助手的價值在於讓人照紀律做決定 |
| 付費資料源 | 免費資料加交叉驗證已能支援大部分功能 |
| 讓 AI 修改政策、局勢參數或計畫單 | 規則由人在冷靜時決定；AI 只能起草建議 |
| 短線預測模型 | 局勢辨識的目的是準備，不是預測明天 |
