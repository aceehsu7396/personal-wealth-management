## 2. 分階段路線

每個階段都要通過驗收，才進入下一階段。

### 階段一：局勢儀表板與局勢劇本
- **內容**：
  - 把現有的每日大盤與總經三支柱整合成局勢分數與局勢狀態（02 §1.1），先用已有資料，再逐步加入信用利差、殖利率曲線、估值與匯率。
  - 局勢劇本（§3.1）：填寫、簽署、版本歷史；局勢改變時在今日頁列出行動。
  - 交易前檢核加入劇本檢查（§5.1）。
  - 大盤回檔階梯（§3.3）。
- **驗收**：
  - 用 2000 年以來的資料回看局勢狀態，確認在 [00 §2](00-總覽.md) 的幾次大回撤中，狀態有轉為收縮或危機。
  - 劇本的每個動作都能在交易前檢核中檢查。

### 階段二：風險儀表板與壓力測試
- **內容**：風險儀表板（§4.1）、壓力測試（§4.2）、部位大小計算器（§4.3）、連續虧損暫停（§4.5）。
- **驗收**：壓力測試用歷史情境估算的損失，和用當時實際資料回算的結果相差在合理範圍內。

### 階段三：情境、校準與檢討
- **內容**：情境工作台（§2.1）、機率校準（§2.2）、局勢判斷回顧（§6.1）、決策日誌（§6.2）、時間加權與金額加權報酬與局勢分段績效（§6.3）、年度檢討報告（§6.4）、walk-forward 與通縮夏普比率（§7.1）。
- **驗收**：累積至少 3 個月的情境紀錄後，能算出布瑞爾分數與校準曲線。

### 階段四：後端與 AI agent
- **內容**：
  - 後端：加密同步與推播（[03 §5](03-AI工具與技術架構.md)）。
  - agent，依序上線：事件監控 → 局勢解讀 → 紅隊 → 交易教練 → 檢討員 → 研究助理。
  - 每個 agent 先建 eval，通過才上線。
- **驗收**：每個 agent 的輸出都引用來源、沒有越權；每月成本在預算內。

## 3. 不做的事

| 不做 | 原因 |
|---|---|
| 自動下單 | 錯誤無法挽回；本系統的價值在於讓人做出更好的決策，而不是取代決策 |
| 付費資料源 | 免費資料加交叉驗證已能支援大部分功能；付費前先證明免費資料不足 |
| 讓 AI 直接修改政策或劇本 | 規則必須由人在冷靜時決定；AI 只能起草建議 |
| 短線預測模型 | 局勢辨識的目的是準備，不是預測明天 |
