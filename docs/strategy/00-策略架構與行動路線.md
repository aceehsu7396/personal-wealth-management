# 00 策略架構與行動路線

## 1. 為什麼要用機構的投資流程

個人投資人與基金經理人最大的差距，通常不在資訊或智商，而在**流程**。機構的每一筆決策都有：

1. **上層約束**：投資政策聲明（IPS）規定能做什麼、不能做什麼
2. **分工**：配置（多少）與選股（買什麼）分開決定
3. **事前紀錄**：買進前寫下理由、預期與失效條件
4. **獨立的風控**：部位上限與熔斷不受個別看法影響
5. **事後歸因**：區分報酬是來自配置、選股，還是運氣

本手冊把這五件事縮小成個人可以執行的版本，最終目標是**成為全職獨立交易者，以自有資產維生**：核心 ETF 拿市場報酬，自有交易策略追求超額報酬，生活費則由獨立的緩衝與提領規則保障。

## 3. 五項設計原則

1. **核心/交易部位（耶魯大學捐贈基金／大衛・史雲生的核心/衛星架構）**：長期報酬的底盤來自核心部位的市場報酬（貝他）。交易部位（衛星）的超額報酬（阿爾法）必須先用回測與虛擬交易證明，再用實單績效證明；連續落後基準，就依規則縮小交易部位。
2. **由上而下決定「多少」，由下而上決定「買什麼」**：總經判斷只能調整配置比例，不能拿來決定買賣個股。
3. **規則先於判斷**：每個構面都要輸出可檢核的東西（分數、門檻、上限），而不只是一個感覺。
4. **先求不大輸，再求贏（霍華・馬克斯／華倫・巴菲特）**：風險預算優先於報酬目標；投資政策聲明的最大回撤是硬上限。
5. **流程可被檢討**：決策品質 ≠ 結果品質（安妮・杜克）。用決策日誌與歸因，區分運氣與能力。

## 4. 行動路線：理論與第一步的連結

專業基金經理人的流程是「政策 → 配置 → 選股 → 風控 → 檢討」，但**個人學習的順序要倒過來先打底**：先確保生活不受市場影響、先用指數 ETF 拿到市場報酬並養成紀律，再把交易策略依序用回測、虛擬交易、小額實單驗證，最後才考慮全職。每個階段都對應手冊的章節與本工具的頁面，完成條件由本工具自動判定（「學習路線 → 行動路線」頁）。

**為什麼交易排在核心之後**

1. **先求不大輸**：沒有緊急預備金時，一次失業或意外就可能被迫在低點賣出。
2. **指數是基準**：交易部位存在的唯一理由是打敗核心 ETF；先持有核心，才有比較的對象。
3. **紀律要先練**：定期定額、記錄交易、每月檢視，這些習慣在小風險的核心部位上先養成，交易時才不會亂。
4. **先證明、再用真錢**：大多數交易者虧損的原因是沒有優勢或不照規則；回測檢驗優勢，虛擬交易檢驗執行。

**交易部位實單解鎖條件**：完成 1.1、1.2、1.4、2.1、2.3、3.1、4.2、4.3。未完成前，策略卡、回測與虛擬帳戶可以隨時使用；實單買進在交易前檢核會標示未通過（可寫例外理由，並計入紀律分數）。

**學習階段與交易部位上限**：交易部位上限依[學習路線](09-十年學習路線.md)的學習階段自動調整——階段一 10%、階段二 20%、階段三 40%、階段四以投資政策上限為準。

## 5. 一句話總結

> **投資政策定框架，核心拿市場報酬，總經調比例，策略經回測與虛擬交易證明才用真錢，風控定大小，紀律保證執行，歸因決定要不要繼續相信自己；五項準備度全過，才轉為全職。**
