# 00 策略架構與行動路線

## 1. 為什麼要用機構的投資流程

個人投資人與基金經理人最大的差距，通常不在資訊或智商，而在**流程**。機構的每一筆決策都有：

1. **上層約束**：投資政策聲明（IPS）規定能做什麼、不能做什麼
2. **分工**：配置（多少）與選股（買什麼）分開決定
3. **事前紀錄**：買進前寫下理由、預期與失效條件
4. **獨立的風控**：部位上限與熔斷不受個別看法影響
5. **事後歸因**：區分報酬是來自配置、選股，還是運氣

本手冊把這五件事縮小成個人可以執行的版本，最終目標是**財務獨立，全職經營自有資產**：
- 生活費來自資產依提領率提領，由獨立的生活費緩衝與提領規則保障，不靠交易收入。
- 核心 ETF 拿市場報酬。
- 自有交易策略先求少賠（控制回撤）、再求多賺。
- 「全職」是不必上班、把時間用來經營資產與人生，不是每天交易（[11 §1.2](11-財務獨立與全職經營.md)）。

**讀圖的三個重點**
1. **上限都從投資政策來**：投資政策（在投資持有與檢討回顧區）的每個數字，流到核心、策略卡、研究卡與風控。每個參數用在哪裡，見[附錄 C 系統關聯與參數地圖](附錄C-系統關聯與參數地圖.md)。
2. **交易部位先證明、再逐筆把關**：
   - 回測要在樣本外勝過買進持有（報酬較高，或夏普比率較好且回撤明顯較小），並通過偏誤檢查（[10 §6.3](10-交易策略開發與回測.md)）
   - 虛擬交易要滿 3 個月、10 筆
   - 每筆實單再過四道關：
     - 先寫**計畫單**：進場、停損、停利、分批與加碼（[04 §0](04-紀律與檢核流程.md)）
     - **局勢參數**決定部位倍數與允許的進場方法（[05 §7](05-總體經濟與政策.md)）

     - **交易前檢核**逐項通過
3. **結果會回饋**：
   - 持股會回頭觸發研究卡的出場提醒；出場管理追蹤每個持倉的停損與停利。
   - 成交後記錄滑價與 R 倍數，計入紀律分數。
   - 檢討與校準回顧決策日誌、情境機率與局勢判斷（[05 §8](05-總體經濟與政策.md)）。
   - 每年的年度檢討報告，依績效歸因與校準結果修訂投資政策、交易部位上限與局勢參數表（[11 §5.1](11-財務獨立與全職經營.md)）。

## 3. 五項設計原則

1. **核心/交易部位（耶魯大學捐贈基金／大衛・史雲生的核心/衛星架構）**：長期報酬的底盤來自核心部位的市場報酬（貝他）。交易部位（衛星）的目標**先求少賠、再求多賺**：在接近持有報酬的前提下，明顯降低回撤；能長期多賺當然更好，但實測顯示這很難（[10 §1.1](10-交易策略開發與回測.md)）。兩者都要先用回測與虛擬交易證明，再用實單績效證明；報酬與回撤都沒有勝過基準時，就依規則縮小交易部位。
2. **由上而下決定「多少」，由下而上決定「買什麼」**：總經判斷只能調整配置比例，不能拿來決定買賣個股。
3. **規則先於判斷**：每個構面都要輸出可檢核的東西（分數、門檻、上限），而不只是一個感覺。
4. **先求不大輸，再求贏（霍華・馬克斯／華倫・巴菲特）**：風險預算優先於報酬目標；投資政策聲明的最大回撤是硬上限。
5. **流程可被檢討**：決策品質 ≠ 結果品質（安妮・杜克）。用決策日誌與歸因，區分運氣與能力。

**AI 的位置**：AI 只說明規則已經算出的結果，不做決定。今日頁、計畫單、市場、決策日誌、績效歸因與年度報告都有「AI 說明」：網站把規則的結果整理成提示詞，你複製到自己的 Claude 對話。不需要付費金鑰，AI 也不能修改任何資料；提示詞預設隱藏金額。

## 4. 行動路線：理論與第一步的連結

專業基金經理人的流程是「政策 → 配置 → 選股 → 風控 → 檢討」，但**個人學習的順序要倒過來先打底**：先確保生活不受市場影響、先用指數 ETF 拿到市場報酬並養成紀律，再把交易策略依序用回測、虛擬交易、小額實單驗證，最後才考慮全職。每個階段都對應手冊的章節與本工具的頁面，完成條件由本工具自動判定（「手冊 → 行動路線」頁）。

| 階段 | 要回答的問題 | 步驟 | 手冊 | 本工具頁面 |
|---|---|---|---|---|
| 一 起步：打好財務地基 | 生活能不能不受市場影響？目標要多少報酬？ | 1.1 設定財務自由目標；1.2 準備緊急預備金；1.3 確認所需報酬是否實際；1.4 簽署投資政策聲明 | [01](01-第一步-財務地基.md)、[02](02-投資政策聲明.md) | 投資持有與檢討回顧 → 目標與政策 |
| 二 核心配置：先買下整個市場 | 不選股，能不能先拿到市場報酬？ | 2.1 建立核心 ETF 持股；2.2 記錄第一筆定期定額；2.3 連續 3 個月定期定額 | [03](03-核心配置與定期定額.md)、[04](04-紀律與檢核流程.md) | 投資持有與檢討回顧 → 持股與風控、交易日誌 |
| 三 看懂市場：總經只調比例 | 現在的景氣、流動性、情緒如何？ | 3.1 第一次總經檢視；3.2 完成 3 個月份的總經檢視 | [05](05-總體經濟與政策.md) | 研究分析 → 市場（局勢狀態、事件日曆） |
| 四 交易策略：回測與虛擬交易 | 我的策略有優勢嗎？我能照規則執行嗎？ | 4.1 寫第一張策略卡；4.2 回測樣本外報酬或風險調整後勝過買進持有；4.3 虛擬交易 3 個月、10 筆 | [10](10-交易策略開發與回測.md)、[06](06-產業與商業模式.md)、[07](07-財務與價值評估.md) | 模擬交易 → 策略卡、回測（含偏誤檢查）、虛擬帳戶 |
| 五 實單驗證與檢討 | 報酬來自能力還是運氣？ | 5.1 第一筆實單（附策略卡與停損）；5.2 第一次季度績效歸因；5.3 第一次交易事後檢討 | [08](08-投資組合策略與風險.md)、[04](04-紀律與檢核流程.md) | 投資持有與檢討回顧 → 交易計畫、交易日誌、風險、績效歸因、檢討與校準 |
| 終點 財務獨立、全職經營 | 能不能、該不該離開本業？ | 全職準備度五項全過 | [11](11-財務獨立與全職經營.md) | 投資持有與檢討回顧 → 目標與政策 |

**為什麼交易排在核心之後**

1. **先求不大輸**：沒有緊急預備金時，一次失業或意外就可能被迫在低點賣出。
2. **指數是基準**：交易部位存在的唯一理由是打敗核心 ETF；先持有核心，才有比較的對象。
3. **紀律要先練**：定期定額、記錄交易、每月檢視，這些習慣在小風險的核心部位上先養成，交易時才不會亂。
4. **先證明、再用真錢**：大多數交易者虧損的原因是沒有優勢或不照規則；回測檢驗優勢，虛擬交易檢驗執行。

**交易部位實單解鎖條件**：完成 1.1、1.2、1.4、2.1、2.3、3.1、4.2、4.3。未完成前，策略卡、回測與虛擬帳戶可以隨時使用；實單買進在交易前檢核會標示未通過（可寫例外理由，並計入紀律分數）。

**學習階段與交易部位上限**：交易部位上限依[學習路線](09-十年學習路線.md)的學習階段自動調整——階段一 10%、階段二 20%、階段三 40%、階段四以投資政策上限為準。

### 4.1 一個交易日怎麼用這個系統

行動路線是「學習的順序」；解鎖實單之後，每個交易日的流程是這樣：

| 時間 | 做什麼 | 在哪裡 | 手冊 |
|---|---|---|---|
| 收盤後 | 收到推播（選用），或打開網站 | 今日頁 | [04 §7](04-紀律與檢核流程.md) |
| 收盤後 | 看「今天要處理的事」：依紀律排序：持倉的停損、論點失效與停利在最前面，接著是到價與進場條件，最後是檢討與待回填的決策 | 今日頁 | [04 §0](04-紀律與檢核流程.md) |
| 收盤後 | 先處理持倉：觸發停損或停利的，照計畫出場；移動停損只往上移 | 持股與風控 → 出場管理 | [08 §3](08-投資組合策略與風險.md) |
| 收盤後 | 看局勢：局勢改變時，部位倍數與允許的進場方法跟著改 | 市場 | [05 §7](05-總體經濟與政策.md) |
| 收盤後 | 要進場的標的寫計畫單：看三級建議，抄下委託單草稿 | 交易計畫 | [04 §0](04-紀律與檢核流程.md)、[04 §0.2](04-紀律與檢核流程.md) |
| 隔天開盤前 | 在券商下單；成交後掛停損或二擇一單 | 券商 | [04 §0.2](04-紀律與檢核流程.md) |
| 成交後 | 從計畫單記錄成交：通過交易前檢核，記下成交價與滑價 | 交易計畫 → 交易日誌 | [04 §1](04-紀律與檢核流程.md) |
| 出場後 | 到期時寫事後檢討；連續虧損暫停時寫暫停檢討 | 交易日誌、風險 | [04 §3](04-紀律與檢核流程.md)、[04 §8](04-紀律與檢核流程.md) |

核心部位不在這個流程裡：每月定期定額照做，不因每日局勢調整。

想先看完整流程怎麼走，請讀 [12 完整操作案例](12-完整操作案例.md)，並在「⚙ 設定 → 示範資料」載入範例逐頁對照。各章引用的專業方法論（達利歐、波特、葛拉漢、索普等）整理在[附錄 A](附錄A-方法論對照.md)；每個方法的原理、算法與限制，詳見附錄 D（[D1](附錄D1-投資政策與總經.md)、[D2](附錄D2-產業與財務.md)、[D3](附錄D3-組合與風險.md)、[D4](附錄D4-交易策略與回測.md)、[D5](附錄D5-紀律檢討與全職.md)）。

## 5. 一句話總結

> **投資政策定框架，核心拿市場報酬，總經調比例，策略經回測與虛擬交易證明才用真錢，風控定大小，紀律保證執行，歸因決定要不要繼續相信自己；五項準備度全過，才離開本業、全職經營自有資產。**
