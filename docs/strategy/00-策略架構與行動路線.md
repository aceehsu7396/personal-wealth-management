# 00 策略架構與行動路線

## 1. 為什麼要用機構的投資流程

個人投資人與基金經理人最大的差距，通常不在資訊或智商，而在**流程**。機構的每一筆決策都有：

1. **上層約束**：投資政策聲明（IPS）規定能做什麼、不能做什麼
2. **分工**：配置（多少）與選股（買什麼）分開決定
3. **事前紀錄**：買進前寫下理由、預期與失效條件
4. **獨立的風控**：部位上限與熔斷不受個別看法影響
5. **事後歸因**：區分報酬是來自配置、選股，還是運氣

本手冊把這五件事縮小成個人可以執行的版本。

## 2. 總架構：一條閉環

```
第 0 層  投資政策聲明（IPS）──────────────────────────── 每年修訂一次
 │
 ▼  由上而下
構面一 總經與政策 ──▶ 策略配置（核心 ETF，長期固定）
                 └─▶ 戰術配置（± 傾斜，有上限，每季調整）
 │
 ▼  由下而上
構面二 產業與商業模式 ┐
構面三 財務與價值評估 ┴─▶ 篩選漏斗：全市場 → 能力圈 → 品質 → 估值 → 觀察名單 → 持有
 │
 ▼
構面四 組合建構與風險：部位大小／集中度／匯率／再平衡／熔斷
 │
 ▼
執行與紀律：交易前檢核 → 分批建倉 → 出場規則 → 交易日誌
 │
 ▼
績效歸因與檢討（配置效果 vs 選股效果）─────▶ 回饋修正第 0 層
```

> 名詞對照：策略配置＝SAA（Strategic Asset Allocation），戰術配置＝TAA（Tactical Asset Allocation）。

### 各層的權限

| 層級 | 可以決定 | 不可以決定 |
|---|---|---|
| 投資政策聲明 | 目標報酬、風險上限、核心/衛星比例、台/美比例 | — |
| 總經 | 股債比例在策略配置 ± 配置微調上限內的傾斜 | 個股進出、超出投資政策上限 |
| 產業 + 財務 | 衛星部位買哪些、買進價 | 衛星總比重 |
| 組合風控 | 每檔部位大小、減碼、熔斷 | 放寬投資政策上限 |
| 紀律 | 擋下不合規交易 | — |

## 3. 五項設計原則

1. **核心/衛星（耶魯大學捐贈基金／大衛・史雲生）**：長期報酬主要來自核心部位的市場報酬（貝他）。衛星部位的超額報酬（阿爾法）必須用績效證明；連續落後基準，就依規則縮小衛星比重。
2. **由上而下決定「多少」，由下而上決定「買什麼」**：總經判斷只能調整配置比例，不能拿來決定買賣個股。
3. **規則先於判斷**：每個構面都要輸出可檢核的東西（分數、門檻、上限），而不只是一個感覺。
4. **先求不大輸，再求贏（霍華・馬克斯／華倫・巴菲特）**：風險預算優先於報酬目標；投資政策聲明的最大回撤是硬上限。
5. **流程可被檢討**：決策品質 ≠ 結果品質（安妮・杜克）。用決策日誌與歸因，區分運氣與能力。

## 4. 行動路線：理論與第一步的連結

專業基金經理人的流程是「政策 → 配置 → 選股 → 風控 → 檢討」，但**個人學習的順序要倒過來先打底**：先確保生活不受市場影響、先用指數 ETF 拿到市場報酬並養成紀律，最後才用小部位練習選股。每個階段都對應手冊的章節與本工具的頁面，完成條件由本工具自動判定（「學習路線 → 行動路線」頁）。

**為什麼選股排在最後**

1. **先求不大輸**：沒有緊急預備金時，一次失業或意外就可能被迫在低點賣股。
2. **指數是基準**：衛星選股存在的唯一理由是打敗核心 ETF；先持有核心，才有比較的對象。
3. **紀律要先練**：定期定額、記錄交易、每月檢視，這些習慣在小風險的核心部位上先養成，選股時才不會亂。

**衛星解鎖條件**：完成 1.1、1.2、1.4、2.1、2.3、3.1。未完成前，研究卡可以先寫來觀察；衛星買進在交易前檢核會標示未通過（可寫例外理由，並計入紀律分數）。

**學習階段與衛星上限**：衛星上限依[十年學習路線](09-十年學習路線.md)的學習階段自動調整——階段一 10%、階段二 20%、階段三 30%、階段四以投資政策上限為準。

## 5. 一句話總結

> **投資政策定框架，總經調比例，產業與財務選標的，風控定大小，紀律保證執行，歸因決定下一年要不要繼續相信自己。**
