# 00a 策略總架構與方法論

## 1. 為什麼要用機構的投資流程

個人投資人與基金經理人最大的差距，通常不在資訊或智商，而在**流程**。機構的每一筆決策都有：

1. **上層約束**：投資政策聲明（IPS）規定能做什麼、不能做什麼
2. **分工**：配置（多少）與選股（買什麼）分開決定
3. **事前紀錄**：買進前寫下理由、預期與失效條件
4. **獨立的風控**：部位上限與熔斷不受個別看法影響
5. **事後歸因**：區分報酬是來自配置、選股，還是運氣

本手冊把這五件事縮小成個人可以執行的版本。

## 2. 總架構：一條閉環

```
L0  投資政策聲明 IPS ───────────────────────────────── 每年修訂一次
 │
 ▼  由上而下 Top-down
構面一 總經與政策 ──▶ 策略配置 SAA（核心 ETF，長期固定）
                 └─▶ 戰術配置 TAA（±傾斜，有上限，每季調整）
 │
 ▼  由下而上 Bottom-up
構面二 產業與商業模式 ┐
構面三 財務與價值評估 ┴─▶ 篩選漏斗：全市場 → 能力圈 → 品質 → 估值 → 觀察名單 → 持有
 │
 ▼
構面四 組合建構與風險：部位大小 / 集中度 / 匯率 / 再平衡 / 熔斷
 │
 ▼
執行與紀律：交易前檢核 → 分批建倉 → 出場規則 → 交易日誌
 │
 ▼
績效歸因與檢討（配置效果 vs 選股效果）─────▶ 回饋修正 L0
```

### 各層的權限

| 層級 | 可以決定 | 不可以決定 |
|---|---|---|
| IPS | 目標報酬、風險上限、核心/衛星比例、台/美比例 | — |
| 總經 | 股債比例在 SAA ± `maxTilt` 內的傾斜 | 個股進出、超出 IPS 上限 |
| 產業 + 財務 | 衛星部位買哪些、買進價 | 衛星總比重 |
| 組合風控 | 每檔部位大小、減碼、熔斷 | 放寬 IPS 上限 |
| 紀律 | 擋下不合規交易 | — |

## 3. 五項設計原則

1. **核心/衛星（Yale 捐贈基金／David Swensen）**：長期報酬主要來自核心的市場 beta。衛星的 alpha 必須用績效證明；連續落後基準，就依規則縮小衛星比重。
2. **由上而下決定「多少」，由下而上決定「買什麼」**：總經判斷只能調整配置比例，不能拿來決定買賣個股。
3. **規則先於判斷**：每個構面都要輸出可檢核的東西（分數、門檻、上限），而不只是一個感覺。
4. **先求不大輸，再求贏（Howard Marks／Warren Buffett）**：風險預算優先於報酬目標；IPS 的最大回撤是硬上限。
5. **流程可被檢討**：決策品質 ≠ 結果品質（Annie Duke）。用決策日誌與歸因，區分運氣與能力。

## 5. 一句話總結

> **IPS 定框架，總經調比例，產業與財務選標的，風控定大小，紀律保證執行，歸因決定下一年要不要繼續相信自己。**
