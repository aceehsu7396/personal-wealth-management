# 04 紀律與檢核流程

> **本章行動**｜階段二　核心配置（從第一筆定期定額開始使用）
>
> - 2.2、2.3 定期定額每次都記入「投資組合 → 交易日誌」，先養成記錄習慣
> - 5.1 第一筆實單：以「策略進場」記錄，連結策略卡並填停損價
> - 5.3 交易滿 6 個月後，在「投資組合 → 交易日誌」完成事後檢討
>
> 完成條件：定期定額記錄涵蓋 3 個月；之後每筆到期的交易都完成檢討。

>
> 規則寫得再好，沒有執行就沒有價值。本文件把各構面的規則變成**例行流程**與**交易前檢核表**。核心定期定額只需要簡單檢核；交易部位（衛星）的實單要通過完整檢核表，並且要先完成行動路線的前置步驟（含回測與虛擬交易）。
>
> 方法論：葛文德／帕布萊檢核表、克萊恩事前驗屍、杜克決策日誌、康納曼行為偏誤。

## 1. 交易前檢核表（本工具「投資組合 → 交易日誌」會強制檢查）

### 買進

| 構面 | 檢核項 | 通過條件 |
|---|---|---|
| 投資政策聲明 | 此筆交易後，核心/交易部位與台/美比例仍在範圍內 | 是 |
| 總經 | 目前的總經判斷不是「逆風」或「強烈逆風」（交易部位新建倉） | 是，或是「恐慌機會」 |
| 策略（策略進場） | 已連結策略卡，且狀態為「實單」 | 是 |
| 策略（策略進場） | 已設停損；本筆停損風險 ≤ 交易部位的 1% | 是 |
| 組合 | 交易部位持有檔數 ≤ 8 | 是 |
| 研究卡（研究卡建倉） | 研究卡完整：一句話論點、失效條件、結論；結論為「值得投資」 | 是 |
| 產業 | 在能力圈內；護城河至少 1 項競爭力量 ≥ 3（五力有評時，平均 ≥ 3） | 是 |
| 財務（自動體檢） | F 分數 ≥ 6（金融業不適用）、ROE ≥ 10%，自動偵測的紅旗都已寫下說明 | 是 |
| 財務 | 現價 ≤ 買進價，上下檔比 ≥ 2 | 是 |
| 組合 | 交易後單檔、產業、美元曝險都不超過上限 | 是 |
| 組合 | 未處於回撤熔斷狀態 | 是 |
| 紀律 | 已填寫事前驗屍 | 是 |
| 紀律 | 偏誤自問（見下方）都已回答 | 是 |

### 賣出

| 檢核項 | 通過條件 |
|---|---|
| 理由對應出場規則 ①–⑤，或策略卡的出場條件／停損 | 是 |
| 不是因為單日/單週的價格波動（停損與策略出場除外：它們本來就依價格觸發） | 是 |
| 已考慮稅與交易成本 | 是 |

**例外**：任一項沒有通過時，仍可交易，但**必須寫下例外理由**；例外交易會降低紀律分數，並在季檢討時逐筆檢視。

### 偏誤自問（每筆都要回答）

1. **確認偏誤**：我找過反方觀點嗎？最強的反方論點是什麼？
2. **錨定**：我的合理價是根據基本面算出來的，還是根據最近的股價？
3. **損失規避**：如果現在沒有持有，我會用這個價格買進嗎？（賣出時用）
4. **過度自信**：如果我錯了，損失是否在可承受範圍內？
5. **從眾/錯失恐懼**：我是因為最近很多人在談，才想買嗎？

## 2. 例行事項

| 頻率 | 時間 | 事項 | 本工具 |
|---|---|---|---|
| 每日（收盤後） | 0–30 分鐘 | **不需要盯盤**。有交易部位時，收盤後檢查策略訊號與停損，下隔日委託；核心部位不看盤 | 模擬交易 → 虛擬帳戶；投資組合 → 交易日誌 |
| 每週 | 30 分鐘 | 閱讀持股與觀察名單的重大新聞；記錄可能觸發失效條件的事件 | 研究分析 → 個股（研究卡） |
| 每月 | 1 小時 | 記錄定期定額；更新總經檢視（三支柱）；確認持股市價（台股每天自動更新） | 投資組合 → 交易日誌、持股與風控；研究分析 → 市場 |
| 每季 | 半天 | 財報季後更新所有研究卡；檢查失效條件；檢查再平衡帶與集中度；績效歸因；檢討本季的例外交易 | 研究分析 → 個股；投資組合 → 持股與風控、績效歸因、交易日誌 |
| 每年 | 1 天 | 投資政策聲明完整檢討；所需報酬重新試算；交易部位比重依歸因結果調整；全職準備度檢核；稅務規劃；學習路線檢討 | 總覽 → 目標與政策；學習路線 → 行動路線 |

## 3. 交易日誌（決策日誌）

每筆交易紀錄：

- 日期、代號、買/賣、股數、價格
- 理由類型：策略進場／策略出場／停損出場、建倉第 1/2/3 批、出場規則 ①–⑤、再平衡
- 對應的策略卡或研究卡；策略進場另記**停損價**（用來計算 R 倍數：損益 ÷ 進場時的停損風險）
- 交易前檢核的結果；例外理由（如果有）
- 當下的情緒（1–5：恐懼 → 貪婪）
- **事後檢討**（交易後 6 個月與 12 個月）：
  - 結果：賺/賠多少，與基準比較
  - 決策品質：當時的資訊與流程是否合理？（與結果分開評分）
  - 學到什麼？要修改哪一條規則？

> 安妮・杜克：好決策可能帶來壞結果，壞決策也可能帶來好結果。**評估的是流程，不是結果。**

## 4. 紀律分數（本工具自動計算）

```
紀律分數 = 40% × 依規交易比例（沒有例外的交易 / 全部交易）
         + 30% × 研究卡完整度（持股中研究卡完整的比例）
         + 30% × 事後檢討完成率（到期應檢討的交易中，已完成的比例）
```

| 分數 | 評語 |
|---|---|
| ≥ 90 | 優秀：流程穩定 |
| 75–89 | 良好 |
| 60–74 | 需改進：檢視例外交易的模式 |
| < 60 | 警示：暫停交易部位新建倉，直到分數回升 |

## 5. 情緒極端時的預先承諾

在冷靜時先寫下來，市場劇烈波動時照做：

- **大跌時**（大盤月跌 > 15%）：「我不賣核心。我檢查熔斷是否觸發。我打開觀察名單，看是否有標的進入強力買進區。」
- **大漲時**（大盤年漲 > 30%）：「我不提高交易部位比重。我檢查是否有持股進入減碼區。我確認再平衡帶。」
- **個股暴跌時**：「我先讀新聞與公告，對照失效條件。48 小時內不下單。」
