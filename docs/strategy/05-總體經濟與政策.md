## 1. 三支柱模型

```
總經分數 = 景氣體制（達利歐／投資時鐘） + 流動性（朱肯米勒） + 情緒溫度（馬克斯）
```

三支柱分開判斷，再綜合起來。任何單一支柱都**不足以**觸發調整。

### 1.1 支柱一：景氣體制（成長 × 通膨）

判斷的是**方向（相對於 3–6 個月前）**，而不是水準。

| 成長＼通膨 | 通膨下降 ↓ | 通膨上升 ↑ |
|---|---|---|
| **成長上升 ↑** | **復甦（金髮女孩經濟）**：股票最佳 | **過熱**：股票仍可、原物料佳、債券差 |
| **成長下降 ↓** | **衰退／通縮**：長債佳、股票差 | **停滯性通膨**：現金最佳，股債皆差 |

**指標（每月更新）**

| 面向 | 美國 | 台灣 |
|---|---|---|
| 成長 | 美國供應管理協會（ISM）製造業採購經理人指數（PMI）（>50 擴張）、非農就業、失業率趨勢（薩姆法則）、實質經濟成長率 | 景氣對策信號（藍→紅燈）、外銷訂單年增率、出口年增率、製造業採購經理人指數 |
| 通膨 | 消費者物價指數（CPI）／核心個人消費支出物價（PCE）年增率趨勢 | 消費者物價指數年增率 |

**成長方向判定**：3 項成長指標中 ≥ 2 項改善 → ↑；≥ 2 項惡化 → ↓；其餘 → 持平。通膨同理。

### 1.2 支柱二：流動性

| 指標 | 寬鬆（+1） | 緊縮（−1） |
|---|---|---|
| 政策利率方向（聯準會／台灣央行） | 降息循環 | 升息循環 |
| 殖利率曲線 10Y−2Y | 由倒掛轉正（注意：轉正初期常是衰退開始） | 持續倒掛 |
| 高收益債信用利差 | 收斂 | 擴大（> 5% 警戒） |
| 央行資產負債表 | 擴表 | 縮表 |
| 美元指數 | 走弱（有利新興市場與台股） | 走強 |

流動性分數 = 各項加總（−5 到 +5）。

### 1.3 支柱三：情緒溫度（馬克斯鐘擺檢核表）

每項勾選「過熱」得 +1、「恐慌」得 −1：

- 評價：大盤本益比相對 10 年歷史百分位（> 80% 過熱、< 20% 恐慌）
- 信用：發債容易、條件寬鬆對比發債困難
- 新股上市／新產品熱度：大量炒作對比無人問津
- 媒體與周遭：人人談股票對比沒人想談
- 散戶融資餘額：快速增加對比大幅下降
- 波動率指數（VIX）：長期 < 13 對比 > 30

溫度 −6 到 +6。**逆向使用**：過熱時收斂風險，恐慌時才是長期投資人的機會。

## 2. 從判斷到行動

| 綜合情境 | 判定條件 | 戰術配置股票傾斜 | 新資金 |
|---|---|---|---|
| 強烈順風 | 復甦體制 + 流動性 ≥ +2 + 溫度 ≤ 0 | +½ 配置微調上限 ～ +配置微調上限 | 優先投入股票、交易部位可正常建倉 |
| 順風 | 體制有利 + 流動性 ≥ 0 | 0 ～ +½ 配置微調上限 | 照常 |
| 中性 | 訊號混雜 | 0 | 照常 |
| 逆風 | 體制不利或流動性 ≤ −2 | −½ 配置微調上限 | 新資金優先補債券/現金，交易部位暫停新建倉 |
| 強烈逆風 | 停滯性通膨／衰退 + 流動性 ≤ −2 + 溫度 ≥ +3 | −配置微調上限（不得低於股票下限） | 同上 |
| **恐慌機會** | 溫度 ≤ −4（不論體制） | 回到策略配置或 +½ 配置微調上限 | 啟用閒置現金分 3 批進場 |

> 恐慌機會優先於體制判斷：馬克斯——「最好的買點，往往是最不想買的時候」。

## 3. 政策面（質化，每季檢視）

- **貨幣政策**：聯準會點陣圖、台灣央行理監事會聲明、選擇性信用管制（房市）
- **財政政策**：美國赤字與發債規模、台灣特別預算
- **產業政策**：美國晶片法案、出口管制、關稅；台灣半導體與人工智慧供應鏈政策
- **地緣政治**：台海、美中科技戰 → 影響台股風險溢酬，是投資政策聲明台/美比例不宜過度偏台的理由之一

政策面**不直接觸發交易**，而是寫進策略卡與研究卡的風險段落，並作為事前驗屍的素材。

## 4. 紀律

1. 每月第一週更新一次總經檢視（本工具「研究分析 → 市場」）
2. 戰術配置傾斜每季最多調整一次，每次最多 ½ 配置微調上限
3. 至少要有兩個支柱方向一致，才調整
4. **不預測**：只判斷「現在處於哪個狀態」，不猜下一季會怎樣
5. 每次判斷都留下紀錄（本工具「研究分析 → 市場」的「總經追蹤」逐月保存判斷、訊號與背後的指標數值，可看判斷歷程、訊號熱度圖與指標走勢），年度檢討時計算戰術配置是否有加分（見 [08](08-投資組合策略與風險.md) 歸因）；若連續 2 年戰術配置都是負貢獻，就把配置微調上限減半

## 5. 資料來源

> 本工具每天由 GitHub 自動讀取下表的公開來源（不需要 API 金鑰），依下方規則判斷 17 個訊號並建立本月檢視；選用的 AI 深入分析也以這些來源為主。判斷仍以你確認後的結果為準，手動修正過的月份不會被自動覆蓋。

| 殖利率曲線、信用利差 | 聖路易聯邦準備銀行經濟資料庫，資料代碼 T10Y2Y、BAMLH0A0HYM2 |
