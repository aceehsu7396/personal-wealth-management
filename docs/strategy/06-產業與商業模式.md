# 06 構面二：產業與商業模式

> **本章行動**｜階段四　交易策略：個股策略的選股工具
>

>

## 1. 篩選漏斗

```
全市場（台股 + 美股）
  │ ① 能力圈：我能用 3 句話說清楚它怎麼賺錢嗎？
  ▼
能力圈內
  │ ② 產業結構：五力平均 ≥ 3
  ▼
好產業
  │ ③ 競爭優勢：至少擁有 1 項 七大競爭力量，且評分 ≥ 3
  ▼
好公司
  │ ④ 財務品質（見 07）
  ▼
觀察名單 ──（價格 ≤ 買進價）──▶ 持有
```

在本系統：選股頁的結果可以勾選多檔，按「研究這 N 檔」，確認後每檔各建一張研究卡並自動體檢（FinMind 免費額度每小時有上限，一次建議 5 檔以內）。完成後到研究卡逐張選結論；選了「值得投資」或「觀察」的，可以一鍵做策略比較（[10 §6.5](10-交易策略開發與回測.md)）。

### 1.1 每日自動研究

每天台灣時間 06:00，GitHub 會自動替你研究一輪。GitHub 的排程常延遲 5～30 分鐘。

1. **選股**：從 7 個篩選組合各選 1 檔，依序是價值、成長、動能、週動能、高股息品質、大型權值、ETF 動能。
   - 每個組合取排名最前的一檔。
   - 最近 30 天已經自動研究過的，或當天被前面的組合選走的，就往下一名，所以每天會輪到不同標的。
   - 篩選資料是前一個交易日收盤後的選股資料。
2. **體檢**：每檔跑和研究卡相同的自動體檢，並給觀察評等（體質佳、留意、偏弱）。評等用預設的投資政策計算，打開研究卡時會依你的投資政策重算。
3. **回測**：觀察評等在「留意」以上的，再用內建範本庫的比較組合回測 5 年，條件和比較與回測頁的預設相同：
   - 收盤判斷、隔日開盤成交；
   - 還原除權息；
   - 最後 30% 為樣本外；
   - 每個標的等額。
4. **保存**：結果發佈在網站上，保留最近 7 天。你打開網站時自動匯入：
   - **新的代號**：建成研究卡，狀態是觀察、待選結論，清單上會標示「每日自動研究・價值」等來源。
   - **已有研究卡的代號**：只更新體檢，不改你的結論與寫的內容。
   - **回測**：存成比較紀錄，標示「每日自動研究」。
     - 為了節省瀏覽器空間，不保存走勢圖；要看走勢圖或建立策略卡，按「全部執行」重跑。
     - 同一檔只保留最新的一筆自動紀錄，最多 20 筆，不會擠掉你自己跑的比較紀錄。

研究卡頁頂端會顯示當天的摘要，例如「研究 7 檔，4 檔留意以上已回測」。在研究卡的搜尋框輸入「每日」，可以只看自動研究的卡。

**限制**
- 只用免費資料：體檢用 FinMind 免費額度，回測用證交所日線。
- 額度用完或資料源沒有回應時，那一檔會標示失敗，其他照常；被跳過的組合當天不補跑。
- 示範模式下不會匯入。

自動研究只是幫你先做功課。要不要投資，仍然由你看完體檢後選結論。

## 2. 能力圈

列出自己真正理解的產業（因為工作、長期研究或使用經驗）。起始建議：

- 自己工作所在的產業（但要注意投資政策聲明的「收入與資產同時受衝擊」限制）
- 每天使用其產品、而且能判斷產品好壞的公司
- 已讀過至少 3 年年報的公司

**不在能力圈內的產業 → 只透過核心 ETF 持有。**

## 3. 產業分析

### 3.1 產業生命週期

| 階段 | 特徵 | 投資重點 |
|---|---|---|
| 萌芽 | 技術未定、虧損 | 不適合交易部位長抱（風險過高），只能觀察 |
| 成長 | 營收高成長、競爭者湧入 | 找出可能的勝出者；估值以本益成長比（PEG）、營收成長為主 |
| 成熟 | 成長放緩、寡占 | 看現金流與股東回饋；估值以本益比（PE）、殖利率、自由現金流（FCF）為主 |
| 衰退 | 需求萎縮 | 原則上避開，除非是資產股 |

### 3.2 波特五力（每項 1–5 分，5 = 對公司最有利）

| 力量 | 5 分（有利） | 1 分（不利） |
|---|---|---|
| 現有競爭強度 | 寡占、理性競爭 | 大量同質競爭者、價格戰 |
| 新進者威脅 | 高資本/技術/法規門檻 | 容易進入 |
| 替代品威脅 | 無替代品 | 替代品多 |
| 客戶議價力 | 客戶分散、轉換成本高 | 少數大客戶 |
| 供應商議價力 | 供應商分散 | 關鍵零組件被壟斷 |

**門檻：五力平均 ≥ 3。**（自我評估，系統不檢查）

### 3.3 台灣產業特別注意

- **供應鏈位置**：在價值鏈的哪一段？能否決定價格？是否只靠單一大客戶（例如蘋果或輝達供應鏈）？
- **景氣循環**：記憶體、面板、航運、鋼鐵 → 一律歸類為林區的「景氣循環股」，套用相反的估值邏輯（本益比低時往往是高點）
- **匯率敏感度**：出口占比高，新台幣升值時毛利率受壓縮

## 4. 競爭優勢：七大競爭力量（每項 0–5 分）

| 競爭力量 | 利益 | 障礙 | 台/美例子 |
|---|---|---|---|
| 規模經濟 | 單位成本隨規模下降 | 對手追上規模的代價過高 | 晶圓代工 |
| 網路效應 | 用戶越多價值越高 | 新進者難以累積用戶 | 支付網路、平台 |
| 反定位 | 新商業模式 | 既有者跟進會傷害自己 | 指數基金對比主動基金 |
| 轉換成本 | 可以維持價格 | 客戶換供應商的成本高 | 企業軟體、晶片設計軟體 |
| 品牌 | 溢價定價 | 長時間累積的信任 | 消費品牌 |
| 壟斷資源 | 獨占專利、人才或執照 | 他人無法取得 | 藥品專利 |
| 流程力 | 更好的品質/成本 | 組織內隱知識，難以複製 | 先進製程良率 |

**門檻：至少 1 項競爭力量 ≥ 3 分。**（自我評估，系統不檢查）護城河的方向（擴大中/持平/縮小中）要寫進論點。

## 5. 商業模式檢核

1. **營收品質**：經常性收入占比？客戶集中度（前 5 大客戶 < 50% 為佳）？
2. **定價能力**：過去 5 年能否在通膨時漲價而不失去客戶？（毛利率是否穩定）
3. **資本密集度**：資本支出 / 營收；高資本密集 + 景氣循環 = 雙重風險
4. **單位經濟**：每多賺一塊營收，需要投入多少資本？（增量投入資本報酬率）
5. **成長驅動**：潛在市場規模、市占率提升空間、新產品；要能量化
6. **經營層與資本配置**（巴菲特）：
   - 經營層持股比例、薪酬與股東利益是否一致
   - 過去的併購是否創造價值
   - 股利/買回/再投資的決策是否合理
   - 說到做到：比對過去法說會的指引與實際結果

## 6. 彼得・林區六類股（決定後續的估值與出場邏輯）

| 類型 | 特徵 | 主要估值 | 賣出時機 |
|---|---|---|---|
| 緩慢成長 | 成長 < 經濟成長率、高配息 | 殖利率 | 配息被削減、殖利率降到歷史低檔 |
| 穩定成長 | 成長 8–12% | 本益比相對歷史 | 估值超過歷史區間上緣 |
| 快速成長 | 成長 > 20% | 本益成長比、營收成長 | 成長率明顯放緩、展店/擴張飽和 |
| 景氣循環 | 獲利隨景氣大幅波動 | 股價淨值比、景氣位置 | 本益比最低、獲利創新高時（反直覺） |
| 轉機 | 從困境恢復 | 資產價值、生存能力 | 轉機完成、回到正常估值 |
| 資產股 | 帳面資產被低估 | 股價淨值比、資產重估 | 資產價值實現 |

## 7. 投資論點格式

研究卡的數字由自動體檢帶入，不需要填寫；但每檔以研究卡建倉的個股，買進前都要想清楚下面七件事。最關鍵的一兩點，寫在研究卡結論的「備註」：

1. **一句話論點**：為什麼市場錯了，或為什麼市場低估了持續性？
2. **林區類型**
3. **3 個關鍵驅動因素**（可量化、可追蹤）
4. **失效條件**：出現什麼情況就代表論點錯了，例如「連續 2 季毛利率 < 40%」「失去前兩大客戶之一」
5. **資訊來源**（費雪閒聊法）：至少 3 個獨立來源——年報/法說會、客戶/供應商/競爭者觀點、產業報告
6. **事前驗屍**：「一年後這筆投資虧了 40%，最可能的原因是什麼？」
7. **政策/地緣風險**（引用 [05](05-總體經濟與政策.md) §3）

## 8. 紀律

- 每季財報後 2 週內更新研究卡，逐條檢查失效條件
- 失效條件一旦觸發 → 依 [08](08-投資組合策略與風險.md) 出場規則 ①，**不得事後修改失效條件來合理化續抱**
