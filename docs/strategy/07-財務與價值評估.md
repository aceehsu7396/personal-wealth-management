# 07 構面三：財務與價值評估

> **本章行動**｜階段四　衛星研究：開始練習選股
>
> - 在研究卡填寫財務品質與三情境合理價，確認買進價與上下檔比
> - 可用研究卡內的「AI 個股分析」預填現價、投入資本報酬率、成長率、F 分數等事實數據（台股另會自動帶入證交所本益比、淨值比、殖利率）；三情境合理價不會預填
> - 4.2 完成第一筆衛星交易：通過「交易日誌」的完整檢核後，依研究卡分批建倉
>
> 完成條件：至少 1 筆衛星買進；衛星比重不超過目前學習階段的上限（階段一 10%）。

> 權限：判斷「公司體質是否合格」與「什麼價格可以買」。
>
> 方法論：葛拉漢安全邊際、葛林布雷、皮奧特洛斯基 F 分數、達摩達蘭故事 + 數字、莫布新反向現金流折現（DCF）、貝尼許 M 分數。

## 1. 財務品質（合格門檻）

### 1.1 核心指標（近 5 年）

| 指標 | 門檻 | 為什麼 |
|---|---|---|
| 投入資本報酬率（ROIC） | 5 年平均 > 加權平均資金成本（WACC） + 3%（一般約 > 12%） | 創造價值的根本來源（葛林布雷） |
| 股東權益報酬率（ROE） | > 15%，且不是靠高負債撐出來的 | 對照資產報酬率（ROA）與負債比，做杜邦分析 |
| 毛利率 | 穩定或上升；5 年標準差 < 5 個百分點 | 定價能力的證據 |
| 自由現金流轉換率 | 自由現金流（FCF） / 淨利 > 80% | 獲利是否是真的現金 |
| 負債 | 淨負債 / 稅息折舊攤銷前獲利（EBITDA） < 2（金融股除外） | 在逆風中生存的能力 |
| 利息保障倍數 | > 8 | |
| 營收成長 | 依林區類型而定 | |

### 1.2 皮奧特洛斯基 F 分數（9 分，每項符合得 1 分）

| 面向 | 項目 |
|---|---|
| 獲利 | ① 資產報酬率 > 0 ② 營業現金流 > 0 ③ 資產報酬率較去年改善 ④ 營業現金流 > 淨利 |
| 槓桿/流動性 | ⑤ 長期負債比下降 ⑥ 流動比率上升 ⑦ 沒有增發新股 |
| 營運效率 | ⑧ 毛利率上升 ⑨ 資產週轉率上升 |

**門檻：F 分數 ≥ 6。**

### 1.3 紅旗（任一項成立 → 暫停研究，直到能解釋清楚）

- 應收帳款或存貨的成長，明顯快於營收（貝尼許 M 分數的核心概念）
- 營業現金流連續低於淨利
- 頻繁變更會計師或會計政策
- 大量關係人交易
- 經營層大量質押或賣出持股

## 2. 價值評估

### 2.1 原則（達摩達蘭）

> 估值 = 故事 + 數字。研究卡上的論點（故事）必須能轉成營收成長、利潤率、再投資率等數字；數字也必須能被故事解釋。兩者不一致，就是警訊。

### 2.2 三種方法交叉驗證

| 方法 | 適用 | 做法 |
|---|---|---|
| **歷史估值帶** | 穩定/快速成長股 | 近 5–10 年本益比（PE）或股價淨值比（PB）的百分位；目前位於 < 30% 百分位 = 相對便宜 |
| **反向現金流折現**（莫布新） | 所有類型 | 以現價反推隱含的 10 年自由現金流成長率；與過去 5 年實際成長、產業成長比較。**隱含成長 > 過去實際成長 × 1.2 → 市場期望過高** |
| **三情境現金流折現 / 目標本益比** | 所有類型 | 悲觀 / 基準 / 樂觀三組假設，算出三個合理價 |

各類型的主要估值依據見 [06 §6](06-產業與商業模式.md)。台股高股息/緩慢成長股，可以加入殖利率法：合理價 = 正常化股利 ÷ 歷史平均殖利率。

### 2.3 三情境合理價

| 情境 | 假設 | 機率（起始值） |
|---|---|---|
| 悲觀 | 失效條件部分發生、成長減半、估值倍數回到歷史低檔 | 25% |
| 基準 | 論點如期實現、估值倍數回到歷史中位數 | 50% |
| 樂觀 | 論點超預期、估值倍數位於歷史上緣 | 25% |

- **期望價值** = Σ 機率 × 情境價格
- **上漲/下跌比** = (樂觀 − 現價) / (現價 − 悲觀)；**> 2 才值得建倉**（朱肯米勒的不對稱）

### 2.4 安全邊際與買進價（葛拉漢）

```
買進價 = 基準合理價 × (1 − 安全邊際)
```

| 公司品質 | 安全邊際 |
|---|---|
| 高品質（七大競爭力量 ≥ 4、F 分數 ≥ 8） | 15% |
| 一般合格 | 25% |
| 景氣循環 / 轉機 | 35% |

本工具的「個股研究」會依此自動計算，並把現價分類為：

| 價位區間 | 條件 | 行動 |
|---|---|---|
| 強力買進區 | 現價 ≤ 悲觀合理價 | 可加速建倉（仍須遵守部位上限） |
| 買進區 | 現價 ≤ 買進價 | 依計畫分批建倉 |
| 持有區 | 買進價 < 現價 ≤ 樂觀合理價 | 不加碼、續抱 |
| 減碼區 | 現價 > 樂觀合理價 | 依出場規則 ② 分批減碼 |

## 3. 紀律

1. 估值試算必須留存三情境的假設，季報後更新；**不得只更新樂觀情境**
2. 合理價只能因為**基本面事實**改變而調整，不能因為股價上漲而上調（避免錨定在股價）
3. 不買虧損且現金流為負的公司（轉機股除外，且最多 2% 部位）
4. 若找不到符合買進價的標的，**現金或核心 ETF 就是預設選項**（核心 ETF 不擇時，見 [03](03-核心配置與定期定額.md)）——不為了「有在投資」而降低標準
