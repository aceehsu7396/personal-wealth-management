# 個人投資與交易策略手冊

目標：**成為全職獨立交易者，以自有資產維生**。用指數型 ETF 作為長期投入的核心，搭配經過回測與虛擬交易驗證的自有交易策略（ETF 與個股，中長期操作），追求最佳的風險調整後報酬；並以專業基金經理人的流程與紀律，逐關驗證之後才轉為全職。

> 本手冊是個人的投資流程紀律文件，不構成投資建議。所有門檻與參數都是**起始值**，需依個人狀況，在年度檢討時修訂。

## 從哪裡開始

**不要從找飆股或直接下單開始。** 先讀 [00 策略架構與行動路線](00-策略架構與行動路線.md)，看懂互動式的系統地圖（目前在哪一步、為什麼），然後照下表一章一章做：每章開頭的「本章行動」寫明要做的步驟、在本工具的哪一頁做、做到什麼程度算完成。本工具「學習路線 → 行動路線」會自動打勾，並在「總覽」顯示下一步。

## 交易部位何時可以用真錢

完成行動路線步驟 1.1、1.2、1.4、2.1、2.3、3.1，以及 4.2（回測通過）、4.3（虛擬交易 3 個月、10 筆）之後。之前策略卡、回測、虛擬帳戶都可以隨時使用，但實單買進在交易前檢核會標示未通過。交易部位上限依學習階段自動調整：階段一 10%、階段二 20%、階段三 40%、階段四依投資政策上限。
