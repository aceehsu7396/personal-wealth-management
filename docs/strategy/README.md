# 個人長期策略投資手冊

目標：以專業基金經理人的研究流程與進出紀律，管理「ETF 核心 + 個股衛星」的台股 + 美股投資組合，力求 10 年內達到財務自由。

> 本手冊是個人的投資流程紀律文件，不構成投資建議。所有門檻與參數都是**起始值**，需依個人狀況，在年度檢討時修訂。

## 從哪裡開始

**不要從研究市場或挑選個股開始。** 先讀 [00 策略架構與行動路線](00-策略架構與行動路線.md)，然後照下表一章一章做：每章開頭的「本章行動」寫明要做的步驟、在本工具的哪一頁做、做到什麼程度算完成。本工具「學習路線 → 行動路線」會自動打勾，並在「總覽」顯示下一步。

## 衛星（個股）何時可以開始

完成行動路線步驟 1.1、1.2、1.4、2.1、2.3、3.1 之後。之前研究卡可以先寫來觀察，但個股買進在交易前檢核會標示未通過。衛星上限依學習階段自動調整：階段一 10%、階段二 20%、階段三 30%。
