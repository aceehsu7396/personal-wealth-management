# 個人長期策略投資手冊

目標：以專業基金經理人的研究流程與進出紀律，管理「ETF 核心 + 個股衛星」的台股 + 美股投資組合，力求 10 年內達到財務自由。

> 本手冊是個人的投資流程紀律文件，不構成投資建議。所有門檻與參數都是**起始值**，需依個人狀況，在年度檢討時修訂。
