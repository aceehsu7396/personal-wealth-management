# 附錄B 名詞解釋

> 回測、選股、研究卡與虛擬帳戶頁面上，名詞旁的「?」顯示的就是這裡的說明。先看懂指標的意思，再判斷值不值得投資。

## 績效與風險

| 名詞 | 說明 |
|---|---|
| 年化報酬 | 把總報酬換算成「平均每年」的複利報酬（CAGR）。比較不同長度的期間時用它，不要用總報酬。 |
| 最大回撤 | 從任何一個高點跌到之後最低點的最大跌幅。代表你在最糟時期要忍受的帳面損失，比波動度更貼近真實感受。 |
| 夏普比率 | 每承擔一單位波動換到多少報酬（年化）。大於 1 算不錯；兩個策略報酬相近時，夏普較高的較好。 |
| 卡瑪比率 | 年化報酬 ÷ 最大回撤（取絕對值）。衡量「為了這個報酬要忍受多深的下跌」，越高越好。在同樣的回撤預算下，卡瑪比率較高的策略可以用較少的犧牲換到相近的報酬。 |
| 勝率 | 獲利交易占全部交易的比例。單看勝率沒有意義：趨勢策略勝率常只有 30–40%，靠少數大賺取勝。 |
| 獲利因子 | 總獲利 ÷ 總虧損。大於 1 才有賺；低於 1.2 時，實單的滑價與成本很可能吃掉優勢。 |
| 持倉時間 | 有持股的交易日占全部交易日的比例。太低代表大部分時間空手，可能錯過漲勢。 |
| β值 | 標的對大盤的敏感度：β = 1 代表和大盤同步，0.5 代表大盤漲跌 1% 時它平均只漲跌 0.5%。 |
| 回檔 | 從近期高點（本系統用 52 週高點）下跌的幅度。跌 10%～20% 稱為修正，跌逾 20% 稱為空頭市場。 |
| 市場廣度 | 上漲的股票是多數還是少數。可以看漲跌家數，或比較等權重指數與市值加權指數：等權重落後時，代表漲勢集中在少數權值股。 |
| 等權重／市值加權 | 市值加權指數依公司市值分配比重，大型股影響最大（例如 S&P 500、SPY）；等權重指數每檔比重相同（例如 RSP），比較能反映一般股票的表現。 |
| 200 日線 | 最近 200 個交易日收盤的平均，約等於一年的平均成本。收盤在它之上、且它向上，一般視為長期多頭。 |
| R 倍數 | 一筆交易的盈虧是起始風險的幾倍。起始風險＝進場價 − 初始停損；漲了 2 倍的起始風險就是 +2R，停損出場約為 −1R。用 R 比較不同價位、不同部位的交易。 |
| 吊燈式停損 | 移動停損的一種：持有期間的最高價減去 k 倍 ATR，只往上移不往下移，讓獲利奔跑、回檔太深就出場。 |
| 時間停損 | 持有超過預定天數仍沒有獲利就出場，避免資金卡在沒有表現的部位。 |
| 滑價 | 實際成交價和計畫價的差距。買進時成交價高於計畫價、賣出時低於計畫價，都會吃掉報酬。 |
| 台指期／夜盤 | 台指期是以加權指數為標的的期貨（代號 TX）。日盤 08:45–13:45；夜盤（盤後交易）從 15:00 到隔天 05:00，讓市場在台股收盤後就能反映美股與國際消息。 |
| 結算價 | 期交所每天依日盤收盤前的成交價算出的價格，用來計算保證金與隔天的漲跌；夜盤的漲跌就是和它比較。 |
| 正價差／逆價差 | 期貨價格高於現貨（加權指數）是正價差，低於是逆價差。夜盤的逆價差擴大，常代表市場預期隔天開低。 |

## 回測方法

| 名詞 | 說明 |
|---|---|
| 樣本內 | 用來選擇與調整參數的期間。樣本內的漂亮績效很容易是「調出來的」，不能單獨相信。 |
| 樣本外 | 回測時刻意保留、沒用來調整參數的最後一段期間。策略在樣本外仍有效，才比較可能在未來有效。 |
| 過度最佳化 | 把參數調到恰好符合過去，對未來沒有意義。徵兆：樣本外明顯變差、參數稍微改動績效就大跌。 |

## 交易與部位

| 名詞 | 說明 |
|---|---|
| R倍數 | 一筆交易的損益除以進場時預定承擔的風險（進場價 − 停損價）。+2R 代表賺到風險的兩倍，−1R 代表照停損出場。 |
| 期望值 | 平均每筆交易賺幾 R：勝率 × 平均獲利 R − 敗率 × 平均虧損 R。大於 0 才有交易的理由。 |
| ATR | 平均真實波幅：標的平常一天波動多少。停損放在 2–3 倍 ATR 外，才不會被正常波動洗出場。 |
| 停損 | 進場前就決定的出場價。目的不是預測，而是把單筆虧損限制在可承受的範圍（每筆 1% 交易部位）。 |
| 局勢參數表 | 每種市場局勢一列：允許的進場方法、部位倍數、停損寬度、加碼與獲利了結方式。局勢一改變，新計畫單的預設值跟著改變；參數只能讓交易更保守。 |
| 確認期 | 新的局勢要連續幾個交易日（本系統為 3 天）都符合規則才算確立，避免一天進出來回跳。崩跌例外，當天確立。 |
| 冷靜期 | 修改規則後的一段等待時間（本系統為 7 天）。期間內照新規則交易前，系統會提醒再確認一次，避免在情緒中改規則。 |
| 逢低階梯 | 事先寫好大盤回檔 10%、20%、30%、40% 時各投入多少預留資金，跌下去時照表執行，不必臨場判斷。 |
| 動能 | 一段期間（例如 6 或 12 個月）的漲跌幅。研究顯示強勢標的在 3–12 個月內傾向延續，但轉折時會急跌，需搭配停損。 |

## 選股與研究卡

| 名詞 | 說明 |
|---|---|
| 本益比 | 股價 ÷ 每股盈餘：市場願意為 1 元獲利付多少錢。低不一定便宜（可能獲利在衰退），要和成長率一起看。 |
| 殖利率 | 近一年現金股利 ÷ 股價。高殖利率若來自股價大跌或一次性配息，未必能持續。 |
| 淨值比 | 股價 ÷ 每股淨值。接近或低於 1 代表價格接近帳面資產，常見於金融與景氣循環股。 |
| 營收年增率 | 本月營收與去年同月相比的成長率。台股每月 10 日前公布，是最即時的基本面數據；看累計年增可避開單月波動。 |
| ROE | 股東權益報酬率：公司用股東的錢一年賺多少。長期 15% 以上通常代表有競爭優勢；要留意是否靠高負債撐起來。 |
| F分數 | 皮奧特洛斯基 F 分數：用 9 項財報變化（獲利、現金流、負債、毛利率、週轉率等）檢查體質是否在改善，0–9 分，6 分以上算合格。 |
| 財報紅旗 | 財報上值得追問的異常，例如獲利一直沒變成現金、應收帳款或存貨暴增。紅旗不一定代表造假，但要查清原因並寫下說明。 |
| 林區分類 | 彼得林區把股票分成緩慢成長、穩定成長、快速成長、景氣循環、轉機、資產股六類，每類的估值方式與出場時機不同。 |
| 外資買超 | 外資（含外資自營商）買進股數減去賣出股數，大於 0 為買超。多半和股價同步，實測預測力很弱，本系統只拿來看趨勢與控制回撤。 |
| 投信買超 | 國內投信（基金公司）的買賣超。投信常在季底作帳，對中小型股影響較大；實測方向不一致，只供參考。 |
| 融資餘額 | 散戶借錢買股的總額。常被當成反指標，但實測融資增加之後的報酬反而較高，只用來看散戶參與程度。 |
| 券資比 | 融券餘額 ÷ 融資餘額。比例高代表看空的人多，若股價上漲可能引發軋空；單獨使用沒有穩定的預測力。 |
| 外資持股比率 | 外資持有的股數占總發行股數的比例。長期上升代表外資逐步加碼，但變化慢，適合當背景資訊。 |
