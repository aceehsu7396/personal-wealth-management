# 附錄B 名詞解釋

> 網站上部分名詞旁的「?」，顯示的就是這裡的說明。先看懂指標的意思，再判斷值不值得投資。名詞依主題分組；同一個名詞只列一次。

## 績效與報酬

| 名詞 | 說明 |
|---|---|
| 年化報酬 | 把總報酬換算成「平均每年」的複利報酬（CAGR）。比較不同長度的期間時用它，不要用總報酬。 |
| 最大回撤 | 從任何一個高點跌到之後最低點的最大跌幅。代表你在最糟時期要忍受的帳面損失，比波動度更貼近真實感受。 |
| 夏普比率 | 每承擔一單位波動換到多少報酬（年化）。大於 1 算不錯；兩個策略報酬相近時，夏普較高的較好。 |
| 卡瑪比率 | 年化報酬 ÷ 最大回撤（取絕對值）。衡量「為了這個報酬要忍受多深的下跌」，越高越好。在同樣的回撤預算下，卡瑪比率較高的策略可以用較少的犧牲換到相近的報酬。 |
| 波動度 | 報酬上下起伏的程度，通常用日報酬的標準差 × √252 換算成年化。本系統的組合年化波動用近一年日線計算。 |
| 時間加權報酬 | 把各期報酬串接起來，排除投入與提領時機的影響，用來評估投資方法本身。 |
| 金額加權報酬 | 也叫內部報酬率（XIRR）：依每筆投入的時間與金額計算的報酬，反映你自己的錢實際賺多少。 |
| 勝率 | 獲利交易占全部交易的比例。單看勝率沒有意義：趨勢策略勝率常只有 30–40%，靠少數大賺取勝。 |
| 獲利因子 | 總獲利 ÷ 總虧損。大於 1 才有賺；低於 1.2 時，實單的滑價與成本很可能吃掉優勢。 |
| 持倉時間 | 有持股的交易日占全部交易日的比例。太低代表大部分時間空手，可能錯過漲勢。 |
| R倍數 | 一筆交易的損益除以進場時預定承擔的風險（進場價 − 初始停損）。+2R 代表賺到風險的兩倍，−1R 代表照停損出場。用 R 比較不同價位、不同部位的交易。 |
| 期望值 | 平均每筆交易賺幾 R：勝率 × 平均獲利 R − 敗率 × 平均虧損 R。大於 0 才有交易的理由。 |

## 風險與部位

| 名詞 | 說明 |
|---|---|
| β值 | 標的對大盤的敏感度（貝他）：β = 1 代表和大盤同步，0.5 代表大盤漲跌 1% 時它平均只漲跌 0.5%。壓力測試用它放大或縮小指數的跌幅。 |
| VaR | 風險值：在一定信賴水準下（本系統 95%），一段期間內「不太會超過」的虧損。1 個月 VaR 5% 代表大約每 20 個月有 1 個月會虧超過 5%。 |
| CVaR | 條件風險值：最差那 5% 情況的平均虧損，比 VaR 更能反映真正的壞日子。 |
| 歷史模擬 | 本系統計算 VaR 的方法：把過去一年每段 21 個交易日的組合報酬排序，直接取最差的 5%，不假設報酬是常態分配。 |
| 風險貢獻 | 每檔持股占組合波動的比例，加總 100%。權重小但波動大、又和其他持股同漲同跌的，風險貢獻會比權重高。 |
| 有效持股數 | 1 ÷ 權重平方和。十檔平均分配是 10 檔；一檔占一半時，即使持有十檔，有效持股數也只有 3 檔多。 |
| 風險預算使用率 | 進行中計畫單的停損風險合計 ÷（交易部位 × 每筆風險 × 最大持倉檔數）。接近 100% 代表交易部位同時承擔的風險已經滿了。 |
| 壓力測試 | 把歷史大跌或假設的衝擊套在今天的持股上，看會虧多少。反向壓力測試則反過來問：大盤要跌多少才會觸發熔斷。 |
| 回撤熔斷 | 組合從高點回撤達投資政策的門檻（預設 −20%）時，暫停交易部位新建倉，所有策略與論點重新檢視；核心定期定額照常。 |
| 目標波動度 | 依標的的波動決定部位：波動越大買越少，讓每個部位對組合的影響接近。 |
| 凱利公式 | 依勝率與盈虧比算出長期成長最快的下注比例。估計誤差很大，實務上只用四分之一或一半。 |
| ATR | 平均真實波幅：標的平常一天波動多少。停損放在 2–3 倍 ATR 外，才不會被正常波動洗出場。 |
| 停損 | 進場前就決定的出場價。目的不是預測，而是把單筆虧損限制在可承受的範圍（每筆 1% 交易部位）。 |
| 吊燈式停損 | 移動停損的一種：持有期間的最高價減去 k 倍 ATR，只往上移不往下移，讓獲利奔跑、回檔太深就出場。 |
| 時間停損 | 持有超過預定天數仍沒有獲利就出場，避免資金卡在沒有表現的部位。 |
| 安全邊際 | 買進價比合理價低多少。本系統預設 25%：買進價 ＝ 基準合理價 ×（1 − 25%），用來容納估值的錯誤。 |
| 再平衡帶 | 各類資產可以偏離目標比例多少（預設 ±5 個百分點）才需要調整；在帶內不動，避免頻繁交易。 |
| 配置微調上限 | 總經判斷可以讓股債比例偏離策略配置的最大幅度（預設 10 個百分點），而且不得低於股票配置下限。 |

## 委託與執行

| 名詞 | 說明 |
|---|---|
| 交易計畫單 | 交易部位每一筆下單前寫好的計畫：設定、觸發、確認、失效點（停損）、部位、委託、出場計畫。成交後轉為進行中，由出場管理追蹤。 |
| 三級建議 | 計畫單依規則給的檢核結果：紀律要求（違反時交易前檢核不通過）、建議（有更保守或更好的做法）、提醒（值得注意的資訊）。每條都附上依據的規則。 |
| 委託單草稿 | 計畫單依計畫列出要在券商下的單：價格對到升降單位、股數拆成整股與零股、成交後要掛的停損或二擇一單，以及預估手續費與證交稅。系統不連接券商、不下單。 |
| 升降單位 | 股價每次能跳動的最小單位，依價位而定，例如 500 到 1,000 元的股票是 1 元、ETF 在 50 元以上是 0.05 元。委託價不在升降單位上會被退單。 |
| ROD、IOC、FOK | 委託的有效期別：ROD 當日有效、掛到收盤；IOC 立即成交，沒成交的部分取消；FOK 全部成交，否則全部取消。 |
| 二擇一單（OCO） | 同時掛停損與停利，一邊成交另一邊自動取消。是券商提供的條件單，不是交易所的委託。 |
| 零股 | 不滿 1,000 股（一張）的股數。盤中零股讓小資金也能分批買進。 |
| 滑價 | 實際成交價和計畫價的差距。買進時成交價高於計畫價、賣出時低於計畫價，都會吃掉報酬。 |
| 停損延遲 | 依計畫單停損出場時，成交價比當時的停損低 2% 以上，代表停損到了沒有立刻執行。每次扣紀律分數 5 分。 |

## 局勢與紀律

| 名詞 | 說明 |
|---|---|
| 局勢 | 依加權指數規則判斷的市場狀態，共七種：崩跌、空頭、修正、反彈初期、多頭過熱、多頭延續、盤整。局勢不決定買什麼，而是決定新計畫單套用局勢參數表的哪一列。 |
| 局勢參數表 | 每種市場局勢一列：允許的進場方法、部位倍數、停損寬度、加碼與獲利了結方式。局勢一改變，新計畫單的預設值跟著改變；參數只能讓交易更保守。 |
| 部位倍數 | 局勢參數表裡，計畫單草稿股數要乘上的倍數，最多 1。例如修正時 0.5，建議 80 股就改為 40 股；0 代表暫停新建倉。 |
| 確認期 | 新的局勢要連續幾個交易日（本系統為 3 天）都符合規則才算確立，避免一天進出來回跳。崩跌例外，當天確立。 |
| 冷靜期 | 修改規則後的一段等待時間（本系統為 7 天）。期間內照新規則交易前，系統會提醒再確認一次，避免在情緒中改規則。 |
| 大盤逢低階梯 | 事先寫好大盤回檔 10%、20%、30%、40% 時各投入多少預留資金，跌下去時照表執行，不必臨場判斷。這是核心部位的錢，不受局勢倍數影響。 |
| 暫停規則 | 連續 3 筆賣出虧損，或本月已實現虧損達交易部位的 6% 時，交易部位暫停新建倉。連續虧損要寫完暫停檢討才解除；單月虧損下個月自動解除。 |
| 紀律分數 | 依規交易比例、研究卡完整度、事後檢討完成率加權，再扣掉停損延遲、滑價、不採納紀律要求的分數。低於 60 時暫停交易部位新建倉。 |
| 學習階段 | 依實單紀錄自動判定的四個階段，交易部位上限依序是 10%、20%、40%、投資政策上限，實際取與投資政策兩者的較小值。 |

## 市場與總經

| 名詞 | 說明 |
|---|---|
| 三支柱 | 本系統的總經框架：景氣體制（成長 × 通膨）、流動性（利率、信用、央行、美元）、情緒溫度。總經只調整股債比例，不決定買什麼。 |
| 景氣體制 | 依成長與通膨相對 3–6 個月前的方向分成四種：復甦、過熱、停滯性通膨、衰退。 |
| 情緒溫度 | 評價、信用、新股熱度、媒體、融資、VIX 六項，過熱 +1、恐慌 −1，加總 −6 到 +6。≤ −4 判定為恐慌機會。 |
| 信用條件 | 高收益債 ETF（HYG）÷ 中期公債 ETF（IEF）的價格比。比值下跌代表市場不願借錢給高風險企業，信用轉緊。本系統用它代替高收益債利差。 |
| 回檔 | 從近期高點（本系統用 52 週高點）下跌的幅度。跌 10%～20% 稱為修正，跌逾 20% 稱為空頭市場。 |
| 市場廣度 | 上漲的股票是多數還是少數。可以看漲跌家數，或比較等權重指數與市值加權指數：等權重落後時，代表漲勢集中在少數權值股。 |
| 等權重／市值加權 | 市值加權指數依公司市值分配比重，大型股影響最大（例如 S&P 500、SPY）；等權重指數每檔比重相同（例如 RSP），比較能反映一般股票的表現。 |
| 200 日線 | 最近 200 個交易日收盤的平均，約等於一年的平均成本。收盤在它之上、且它向上，一般視為長期多頭。 |
| 殖利率曲線倒掛 | 短天期公債殖利率高於長天期（例如 10 年減 2 年為負）。歷史上常在衰退前出現，而「由倒掛轉正」往往更接近衰退開始。 |
| 動能 | 一段期間（例如 6 或 12 個月）的漲跌幅。研究顯示強勢標的在 3–12 個月內傾向延續，但轉折時會急跌，需搭配停損。 |
| 事件日曆 | 列出持股與計畫單的除權息、法說會、財報日，以及全市場的重大經濟數據。事件前幾天，計畫單會建議先別進場或部位減半。 |
| 除權息 | 公司配發股票股利或現金股利時，股價在除權息日依配發金額調降。持有到除息前一天才能領到股利。 |
| 法說會 | 法人說明會：公司向投資人說明營運與展望。前後股價波動常較大，可能跳空。 |
| 進場條件 | 事先寫好的技術條件，例如突破 55 日新高、拉回到 20 日線，用來提醒建立計畫單，不是買進指令。 |
| 台指期／夜盤 | 台指期是以加權指數為標的的期貨（代號 TX）。日盤 08:45–13:45；夜盤（盤後交易）從 15:00 到隔天 05:00，讓市場在台股收盤後就能反映美股與國際消息。 |
| 結算價 | 期交所每天依日盤收盤前的成交價算出的價格，用來計算保證金與隔天的漲跌；夜盤的漲跌就是和它比較。 |
| 正價差／逆價差 | 期貨價格高於現貨（加權指數）是正價差，低於是逆價差。夜盤的逆價差擴大，常代表市場預期隔天開低。 |

## 檢討與校準

| 名詞 | 說明 |
|---|---|
| 決策日誌 | 交易以外的重大決定（戰術傾斜、修改局勢參數或投資政策）的紀錄：事前寫判斷、理由、信心與事前驗屍，到檢討日回填結果與決策品質。 |
| 事前驗屍 | 做決定前先假設結果很差，寫下最可能的原因，用來找出被忽略的風險。 |
| 情境工作台 | 對一個問題寫 2 到 4 個情境，機率合計 100%，並寫下觸發條件、早期訊號與預備行動；到期後標記實際發生的情境。 |
| 布瑞爾分數 | 機率預測的計分：Σ（機率 − 是否發生）²，0 最好。給 70% 而發生，得 0.09；沒發生，得 0.49。 |
| 校準 | 給 70% 的事，長期大約七成會發生，就是校準良好。 |
| 年度檢討報告 | 每年 1 月在「檢討與校準」頁產生：目標進度、報酬、計畫執行、違規與暫停、判斷品質，以及依固定規則產生的修訂建議。 |

## 回測方法

| 名詞 | 說明 |
|---|---|
| 樣本內 | 用來選擇與調整參數的期間。樣本內的漂亮績效很容易是「調出來的」，不能單獨相信。 |
| 樣本外 | 回測時刻意保留、沒用來調整參數的最後一段期間。策略在樣本外仍有效，才比較可能在未來有效。 |
| 過度最佳化 | 把參數調到恰好符合過去，對未來沒有意義。徵兆：樣本外明顯變差、參數稍微改動績效就大跌。 |
| 前進分析 | 英文 walk-forward：把回測期間切段，每段只用之前的資料挑參數、再到下一段實測，模擬「當時不知道未來」的真實情況。 |
| 折減夏普比率 | 英文 Deflated Sharpe Ratio：把「試過幾次」算進去的夏普比率。試越多次，運氣碰到高夏普的機會越大，門檻就越高。 |

## 選股與研究卡

| 名詞 | 說明 |
|---|---|
| 研究卡 | 對單一標的的判斷：自動體檢（品質、成長、財務安全、估值、股利）加上你的結論，算出三情境合理價、買進價與進出場建議。 |
| 策略卡 | 一套可以重複執行的交易規則：範本、參數、標的、進出場規則與每筆風險。狀態從開發中、虛擬交易到實單，只有實單狀態才能用真錢。 |
| 能力圈 | 你真正懂的生意範圍：能用三句話說清楚它怎麼賺錢、什麼情況會讓它不再賺錢。不在能力圈內的，只透過核心 ETF 持有。 |
| 護城河 | 讓公司長期維持高報酬、競爭者難以複製的優勢，例如規模經濟、轉換成本、品牌、網路效應。 |
| 本益比 | 股價 ÷ 每股盈餘：市場願意為 1 元獲利付多少錢。低不一定便宜（可能獲利在衰退），要和成長率一起看。 |
| 本益成長比 | 本益比 ÷ 盈餘年成長率（%）。1 左右通常算合理，適合比較快速成長股。 |
| 殖利率 | 近一年現金股利 ÷ 股價。高殖利率若來自股價大跌或一次性配息，未必能持續。 |
| 淨值比 | 股價 ÷ 每股淨值。接近或低於 1 代表價格接近帳面資產，常見於金融與景氣循環股。 |
| 營收年增率 | 本月營收與去年同月相比的成長率。台股每月 10 日前公布，是最即時的基本面數據；看累計年增可避開單月波動。 |
| ROE | 股東權益報酬率：公司用股東的錢一年賺多少。長期 15% 以上通常代表有競爭優勢；要留意是否靠高負債撐起來。 |
| F分數 | 皮奧特洛斯基 F 分數：用 9 項財報變化（獲利、現金流、負債、毛利率、週轉率等）檢查體質是否在改善，0–9 分，6 分以上算合格。 |
| 財報紅旗 | 財報上值得追問的異常，例如獲利一直沒變成現金、應收帳款或存貨暴增。紅旗不一定代表造假，但要查清原因並寫下說明。 |
| 林區分類 | 彼得林區把股票分成緩慢成長、穩定成長、快速成長、景氣循環、轉機、資產股六類，每類的估值方式與出場時機不同。 |
| 外資買超 | 外資（含外資自營商）買進股數減去賣出股數，大於 0 為買超。多半和股價同步，實測預測力很弱，本系統只拿來看趨勢與控制回撤。 |
| 投信買超 | 國內投信（基金公司）的買賣超。投信常在季底作帳，對中小型股影響較大；實測方向不一致，只供參考。 |
| 融資餘額 | 散戶借錢買股的總額。常被當成反指標，但實測融資增加之後的報酬反而較高，只用來看散戶參與程度。 |
| 券資比 | 融券餘額 ÷ 融資餘額。比例高代表看空的人多，若股價上漲可能引發軋空；單獨使用沒有穩定的預測力。 |
| 外資持股比率 | 外資持有的股數占總發行股數的比例。長期上升代表外資逐步加碼，但變化慢，適合當背景資訊。 |

## 財務獨立

| 名詞 | 說明 |
|---|---|
| 可持續提領率 | 每年從資產提領生活費的比例，依歷史最差情境推算能長期維持的水準。本手冊建議 3.5%。 |
| 全職門檻 | 年生活費 ÷ 提領率。例如每月生活費 5 萬、提領率 3.5%，門檻約 1,714 萬。 |
| 生活費緩衝 | 另外準備、不投入股市的現金或短債，全職前要達 24 個月生活費，讓空頭時不必被迫賣股。 |
| 全職準備度 | 離開本業前要全部通過的五項：資產達門檻、生活費緩衝、實單紀錄、績效、紀律。 |
| 報酬順序風險 | 同樣的平均報酬，大跌出現在提領初期，資產會耗盡得快很多。全職者因此更需要「少賠」。 |
| 三桶金 | 依用途把資產分成三份：短期生活費（緩衝）、長期成長（核心 ETF）、主動經營（交易部位）。 |
