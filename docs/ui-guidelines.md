# 介面規範：每一頁都簡潔易讀

> 適用於本網站所有新頁面，以及舊頁面被修改的部分。2026-11-12 訂定。審查流程見 `.claude/skills/ui-review/SKILL.md`；自動檢查見 `scripts/ui-check.mjs`。

## 1. 以筆記型電腦為主

- **主要畫面**：寬 1366 到 1440、高 768 到 900，淺色與深色模式都要檢查。
- **第一個畫面**（不捲動時）一定要看到：
  - 頁面標題與一句話說明
  - 這頁最重要的結論或數字
  - 主要按鈕（如果這頁有要你做的事）
- **兩欄排版**：寬度夠時，把「結論與動作」和「依據與明細」放成左右兩欄；但一段文字的寬度不超過約 45 個中文字（Tailwind `max-w-prose` 左右），太寬會難讀。
- **手機**（390 寬）只保證可用：不能水平捲動；表格可以在自己的區塊內橫向捲動；按鈕點得到。

## 2. 每頁一個主要任務

- 頁首用 `PageHeader`：標題、一句話說明這頁做什麼，以及下一步。
- 一頁只放一個主要按鈕（實心色）；其他動作用文字連結或外框按鈕。
- 和這頁任務無關的內容，連到別頁，不要塞進來。

## 3. 資訊分三層：結論 → 依據 → 明細

| 層 | 放什麼 | 怎麼呈現 |
|---|---|---|
| 結論 | 現在該知道或該做的事 | 直接顯示；一句話或一個數字 |
| 依據 | 為什麼是這個結論：規則、數據 | 結論下方短句；較長的用 `Disclosure` 收合 |
| 明細 | 完整數據、歷史、計算過程 | `Disclosure` 或表格，預設收合 |

## 4. 數量上限

- 一張卡片：最多 5 到 7 個數字或欄位。
- 一張卡片：最多一個主要按鈕。
- 表格：預設最多顯示 10 列，其餘用「顯示全部」展開（`DataTable` 內建）。
- 一組統計格：一列最多 4 個。
- 同一個畫面裡的醒目顏色（警示、強調）不超過三處；什麼都標紅，就等於沒有標。

## 5. 文字

- 句子短，一句一件事。能用條列就不要寫成一大段。
- 用繁體中文白話；英文只放在括號裡當原名。
- 專有名詞第一次出現時用 `Term` 元件附名詞解釋。
- 數字附單位與日期，例如「38,936 點（11/6 夜盤）」。
- 提示文字說明「為什麼」和「下一步」，不要只說「注意」。

## 6. 建議的三級語氣

進出場助手與檢核結果一律用 `AdviceList`，三級樣式固定：

| 等級 | 意思 | 樣式 |
|---|---|---|
| 紀律要求 | 違反時交易前檢核不通過 | 紅色左邊框、「紀律要求」標籤 |
| 建議 | 符合規則，但有更保守或更好的做法 | 琥珀色左邊框、「建議」標籤 |
| 提醒 | 值得注意的資訊 | 灰藍色左邊框、「提醒」標籤 |

每條都要附「依據」：哪一條規則、哪個數據。

## 7. 顏色與元件

- 語氣顏色只用四種：good（靛藍）、warn（琥珀）、bad（紅）、info（灰）。定義在 `src/components/ui/tone.ts`。
- 漲跌顏色沿用現有：上漲靛藍、下跌紅色。
- 一律使用 `src/components/ui/` 的共用元件：

  | 元件 | 用途 |
  |---|---|
  | `PageHeader` | 頁首：標題、說明、主要動作 |
  | `Card` | 區塊卡片：標題、說明、內容、右上角動作 |
  | `StatTile` | 一個數字加說明 |
  | `Badge` | 狀態標籤 |
  | `AdviceList` | 三級建議 |
  | `DataTable` | 可排序、預設 10 列的表格 |
  | `Disclosure` | 收合的依據與明細 |

## 8. 無障礙

- 標題層級不跳級：頁面 `h1`，區塊 `h2`，區塊內 `h3`。
- 每個按鈕、連結都有看得懂的名稱；只有圖示的按鈕要加 `aria-label`。
- 文字不小於 12px；說明文字用 `text-xs`（12px）以上。
- 顏色對比符合 WCAG AA；不能只靠顏色傳達意思，例如漲跌要有正負號。
- 所有操作都能用鍵盤完成。

## 9. 審查清單（上線前逐條確認）

1. 第一個畫面看得到標題、一句話說明、最重要的結論、主要按鈕。
2. 一頁只有一個主要按鈕；每張卡片最多一個。
3. 結論、依據、明細三層分明；明細預設收合。
4. 數量沒有超過第 4 節的上限。
5. 文字短、白話，專有名詞有解釋。
6. 建議用三級語氣，且附依據。
7. 使用共用元件與四種語氣顏色。
8. 筆電淺色、深色都清楚；手機不水平捲動。
9. 自動檢查沒有錯誤：溢出、主控台錯誤、標題跳級、無名稱按鈕、小字、對比。
